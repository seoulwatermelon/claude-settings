# Univ-Harness Command

이 커맨드는 **univ-harness** 스킬을 호출하여 기획자-생성자-평가자 3인조 루프를 실행합니다.

## Usage

```
/univ-harness <작업 지시>
```

## Examples

```
/univ-harness 영문 요강에 임용쿼터 섹션 추가해줘
/univ-harness 한글 공고문과 영문 공고문 날짜 교차검증
/univ-harness 이 함수 리팩토링하고 테스트 추가
```

## How It Works

1. `Skill` 도구로 `univ-harness` 스킬을 로드합니다
2. 스킬의 3-Role Loop 프로토콜을 따릅니다:
   - **[기획자]** 목표/규칙/체크리스트 수립
   - **[생성자]** 초안 작성
   - **[평가자]** 100점 기준 채점
   - **[루프]** 100점까지 최대 5회 반복
3. 최종 통과된 결과물만 보고합니다

## When to Use

- `/univ-harness` — 대학 행정문서 작성/검수, 다국어 문서 교차검증, 코드 품질 검증
- 높은 정확도가 요구되는 모든 작업에 활용 가능
