BK21 2차 중간평가 기초통계 "2-4. 외국인교원 지원프로그램 현황 및 실적" 작성 시 (전략기획팀 협조요청, 교원인사팀 담당, 2년 주기). 2026.6.2. 작업 기준.

**데이터 소스**: `부서별결의서조회_*_종합.xlsx` Sheet1. 핵심 열 — J=지불일자, K=적요, U=예금주명, F=차변(발생액), G=대변(실지급액). 각 지급은 2행 구조: `지불=비대상`(차변=발생액 라운드값) + `지불=날짜`(대변=실지급, 원천징수 후). 발생액은 비대상행을 지불행과 **시트 순서대로 FIFO 페어링**해 날짜 부여.

**집계 규칙(2년 전 보고서 역산·검증)**:
- **학년도 기준** (2025학년도=2025.3.1~2026.2.28), 연도배정은 **지불일자(J)** 기준 (적요의 평가연도 아님)
- **발생액(차변, 라운드값)** 사용 — 실지급액 아님
- 포함 항목: 숙소지원 / 외국인(교육전담)전임교원 인센티브 / SKKU(Rising)-Fellowship 특별장려금·특별연구비 / 교수업적평가 성과장려금 / Fellowship 수상부상
- 제외: 면접비·심사비·건강검진·퇴임기념품·연장근로·회의비 (성과장려금은 전체교원 대상이나 외국인분은 포함)
- 검증 일치: 무함마드칸 2023학년도 26M, 조슈아잭맨 21.5M

**예금주명 매핑**: 외국인은 U열이 영문/한글 혼재. 영문→한글은 적요(K)에 한글명이 같이 적혀 교차검증 가능. 주의: SIMMYUNGYO=YOOKSIMMY=육심명(성·이름 순서 바뀐 표기 동일인). 명단(C열 한글명)에 매칭되는 사람만 집계, 한국인 교수(성과장려금 다수)는 자동 제외.

**주의**: "기준일 YYYY.M.D" 보고서는 해당 학년도가 **부분집계**일 수 있음(예: 2024.7.18 기준 → 2024학년도 7월까지만). 신규 추가 교원은 과거열이 공란이라 누락 가능 — 결의서 범위 내 학년도는 보강 가능, 범위 밖(결의서 시작 이전)은 불가.

재현 스크립트: `BK/_build_bk_update.py` (매핑 dict·분류·페어링·시트생성 포함). 생성 시트: `백데이터(2026.6.2)`, `영문명 매핑표`.
