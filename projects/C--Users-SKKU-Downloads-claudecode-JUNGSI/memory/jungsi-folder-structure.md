2026-10-26 전면 재정리. 최상위 17개 폴더(4,915파일 18.4GB)를 네 덩어리로 줄였다.

```
JUNGSI\
├ 00_여기부터_읽으세요.md   운영 규칙 (새 담당자가 먼저 읽는 문서)
├ 00_공통\                  연도 무관: 01_우수학술지_Toptier목록 / 02_학과_건제순_기준표 / 99_환경백업
├ 01_교원확보율\            연중 상시 업무
├ 2027_정시채용\            01_초빙세부내역 02_공고_모집요강 03_원서접수_경쟁률
│                           04_심사위원_추천_제척 05_서류심사 06_연구력검증_GPR_DPR_PR
│                           07_2단계심사 08_원테이블_결과보고 09_면접일정조율
│                           10_교원인사협의회_임용
├ 2028_정시채용\            같은 10단계 빈 골격
├ _정리_수정전원본\         경로 고친 스크립트 193개의 수정 전 원본
└ _정리이력.json            이동 전부 {from,to} 기록 + 끊긴참조_12건
```

**단계 폴더 안은 어디나 같은 다섯 칸**: `01_원본데이터`(받은 것) / `02_산출물`(만든 것) /
`_scripts` / `_work`(지워도 되는 중간물) / `_archive`(구버전).
작업단위가 여럿이면 `03_` 부터 번호를 이어 붙인다(01·02는 원본·산출물 자리로 비워 둠).
예외는 `10_교원인사협의회_임용` — 자체 흐름이 `01_기본자료(GPR)`~`15_비용처리`로 길어
그 번호를 두고 단계 전체 산출물만 `00_종합산출물`에 모았다.

**Why:** 연도 폴더가 한 바퀴라 끝난 해는 그대로 두고 다음 해 폴더에서 새로 시작하면 된다.
번호가 업무 순서라 위에서 아래로 내려가면 채용 한 바퀴가 끝난다.

**How to apply:**
- 경로를 말할 때 2026-10-26 이전 이름을 쓰지 말 것. 전부 위 구조로 옮겨졌다.
  옛 이름 → 새 자리는 `_정리이력.json` 에 있다. 자주 나오는 것만 적으면
  `..._심사위원추천`→`04_심사위원_추천_제척`, `..._서류심사_합격`→`05_서류심사`,
  `..._2단계`→`07_2단계심사`, `..._원테이블`→`08_원테이블_결과보고`,
  `..._교인협`→`10_교원인사협의회_임용`, `recruit_jungsi_detailfieldsubmit`→`01_초빙세부내역`,
  `recruit_jungsi_gonggomun`→`02_공고_모집요강`, `calendar_recruiting`→`09_면접일정조율`,
  `..._우수학술지_업데이트`→`00_공통\01_우수학술지_Toptier목록`.
- 새 연도는 `2028_정시채용\` 골격에서 시작. 직전 연도 폴더는 읽기만 한다.
- 우수학술지 목록은 새로 만들지 않고 `00_공통`에서 갱신해 계속 쓴다.
- **`.py` 는 전부 `_scripts`(또는 `_work`·`_archive`) 안에 있다.** 자료 폴더에 두지 말 것.
  `01_원본데이터`는 받은 것만, `02_산출물`은 만든 것만.
- **스크립트에 절대경로를 박지 말 것.** 표지 파일(`00_여기부터_읽으세요.md`)을 찾아
  루트까지 올라가고, 경로는 루트 기준 전체 상대경로로 쓴다. 스크립트 155개가 이 방식이고
  코드에 박힌 절대경로는 0건이다.
  ```python
  _HERE = os.path.dirname(os.path.abspath(__file__))
  _ROOT = _HERE
  for _ in range(10):
      if os.path.exists(os.path.join(_ROOT, '00_여기부터_읽으세요.md')):
          break
      _ROOT = os.path.dirname(_ROOT)
  ```
  `os.path.dirname(_HERE)` 를 몇 번 쓰는 깊이 방식은 금지 — 스크립트가 `_scripts\` 에
  있는지 `_work\doc_audit\` 에 있는지에 따라 횟수가 달라져 실제로 15군데가 깨졌다.
  앵커 정의는 첫 사용보다 위에 둘 것(`NameError` 는 `py_compile` 로 안 잡힌다).
- 학과 순서는 가나다순이 아니라 **건제순**. 기준표는 `00_공통\02_학과_건제순_기준표\`.
