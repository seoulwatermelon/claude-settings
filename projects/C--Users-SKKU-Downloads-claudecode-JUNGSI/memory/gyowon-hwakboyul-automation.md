`JUNGSI/01_교원확보율/` — 학과별 TO 배정 전에 교원확보율을 갱신하는 작업. 2026-09-07 구축.

**사슬**: `_설정`(기준일·교수유형표) → `26.3 예상전임교원수`(AT·AU·AY·AV·AW·AX **전부 엑셀 수식**)
→ `(종합) 2026 확보율` SUMIF → U=(Q+R)/P, V=T/P.
매 학기 교원조회·임용예정자 명단 2파일을 넣고 `_scripts/config.py` 만 고친 뒤
`build.py` → `verify.py`. **다음 학기엔 이번 OUT 을 PREV 로 옮겨 적어야 한다**(안 하면 오류 없이 옛 명부로 돌아감).

**시트명은 (종합) 수식이 참조하므로 못 바꾼다** — 이름은 26.3/2026이지만 실제 기준일은 `_설정!B3`.

**사용자 판단 대기 (2026-09-07 기준 미결)**
- (종합)에 **코드 102 행 추가 여부** — 학부대학(어학) 19명이 확보율 어디에도 안 잡힘.
  정리표엔 102가 있는데 (종합)엔 학부대학 행이 101뿐. 직전 산정본부터 그랬음.
- 매뉴얼 **1-1절 시스템 경로** 비어 있음. 교원조회에 「교수유형」 포함법을 적으면 경고 57건 소멸.
- `피벗_책임학점_퇴직반영필요` **필터 재설정** — AU가 수식이 되며 빈칸이 `0` → 공백으로 바뀜.

**알고 넘어가는 미집계**(`config.KNOWN_NO_CODE` / `KNOWN_UNMATCHED_CODES`):
의학과(임상) 542명(사용자 확인 완료), 학부대학(어학) 19명.

**이 통합문서의 함정**
- **개인번호는 반드시 숫자.** 텍스트로 바꾸면 `책임학점(2025)` 의 XLOOKUP 이 911행→0행으로 죽고,
  옆 피벗은 옛 캐시값을 보여줘 고장이 안 보인다.
- 교원조회에 없는 열(한문·영문성명, 연락처, 승진트랙 등 16개)은 `writer.CARRY_COLS` 로 승계.
  보직만 예외 — 보직소속이 직전과 같은 사람에게만 물려준다(안 그러면 옛 보직명+새 보직소속).
- `_변동내역` 탈락 사유는 **추정**. 직전 AU에 '정년' 말고 손으로 넣은 '퇴직예정'도 있어,
  값 유무로만 가르면 85명 중 37명이 틀린다.
- openpyxl 저장은 피벗을 깬다(부품 72→61). Excel COM + `DispatchEx`(전용 인스턴스).
