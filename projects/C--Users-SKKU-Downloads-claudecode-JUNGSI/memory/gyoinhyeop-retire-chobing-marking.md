2027 정시채용 교인협 자료(`2027_정시채용\10_교원인사협의회_임용\4. 참고자료`)에서 **3단계 진출 학과**의 (a) 3년내 정년 퇴임예정 교원, (b) 최근 3년 초빙 사례를 각 원본 파일에 열 추가로 표시하는 작업. 스크립트: `_mark_retire.py`, `_mark_chobing.py`.

**3단계 진출 학과 = 17개** — `2027_정시채용\08_원테이블_결과보고\2027_학과추천_회신현황표_260618.xlsx`에서 결정유형(J열)이 `전형중단`·`미채용`이 **아닌** 학과. (제외된 것: 정치외교/신소재/식품생명/응용AI×2/임상연구설계평가)

**퇴임 표시** (`소속별교원명단_260703.xlsx`, 시트명 `sheet` 992행):
- C열=행정관리소속(학과), Q열=정년예정일(Excel serial), G열=직종, E열=의대소속, W열=초빙분야
- 대상: **G열 직종='전임교원'만** (`(외)전임교원`·`총장` 제외)
- 3년내 = 정년예정일 **≤ 2029-08-31** (사용자 최종 기준. 처음 2029-02였다가 8월로 변경)
- 의학과는 회신현황표 표기가 `의학과(기초)`라 **E열=기초의학**만 매칭
- 바이오신약·규제과학과, 지능형정밀헬스케어융합전공은 C열 직속 교원 없음 → **겸직발령소속(AE/AG/AI/AK/AM/AO/AQ)** 으로 매칭
- 결과: 진출학과 소속 290명, 3년내 퇴임 32명. 추가열 AR~AU(3단계진출학과/매칭경로/정년예정일/3년이내퇴임)

**초빙 표시** (`전임교원 임용예정자 명단(2019.2학기~).xlsx`, 시트 `일자,시간별`):
- B열=학과, C열=채용분야, G열=채용구분(정시/상시), V열=최종임용일(문자열 `YYYY.MM.DD.` 또는 datetime 혼재)
- 최근3년 = 임용일 **2023-09-01 ~ 2026-08-31**
- 교원유형 필터 없음(예시의 지영아=실무형교육전담도 포함)
- 결과: 41건. 추가열 AO~AQ(3단계진출학과/최근3년초빙/최종임용일파싱)
- 사용자 파싱 형식: `성명(YY.M/정시or상시/채용분야)`

**함정 — 학과명 구분자 정규화 필수**: 임용파일 B열은 가운뎃점 대신 **마침표**를 씀(`아동.청소년학과`, `바이오신약.규제과학과`) vs 회신현황표는 가운뎃점(`·`). `re.sub(r'[·・.\s]','',name)`로 정규화해 비교해야 아동·청소년학과가 매칭됨.

**함정 — openpyxl multi-sheet 저장**: `wb.active` 참조 시 엉뚱한 빈 시트에 기록될 수 있음. 반드시 `wb[시트명]` 명시하고 `wb.active = wb.sheetnames.index(시트명)`로 되돌릴 것. 잉여 빈 시트는 명시 삭제.

두 산출물은 짝: 퇴임(누가 나감) + 초빙(최근 뭘 뽑음)으로 학과별 채용 필요 근거 정리용. 최종 사람 확정은 사용자가 함. [[folder-wontable-gyoinhyeop-split]] [[email-no-tables]]
