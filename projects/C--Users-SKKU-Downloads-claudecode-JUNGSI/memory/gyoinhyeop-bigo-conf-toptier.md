교인협 자료 **연구역량 > 주요 연구력 지표(국제A, 2023~2026)** 표의 **비고란** 작성 규칙(주저자만 고려):

**재료**: `00_공통\01_우수학술지_Toptier목록/03_학술지정보업로드/학술지정보업로드_2027_종합_표기값매핑_v2_탑티어재매핑.xlsx` > `sheet` 시트. E=관리번호, I=연구자구분(주저자="책임 또는 제1저자"), M=게재년월, **AS=기간내(2023.4~2026.4, "○"/"X")**, AO=최종tier(Top-tier/2nd-tier), AW=소프트웨어컨퍼런스tier, AX=정통(정보통신)컨퍼런스tier.

**기간필터 필수**: 2023.4~2026.4 실적만 인정 → **AS열="○"인 행만** 사용(탑티어 AO는 기간필터가 없어 반드시 AS로 걸러야 함. 컨퍼런스 AW/AX는 "(기간반영)"이라 기간외는 "(기간외)"로 이미 제외되나 AS도 함께 적용).

**컨퍼런스**(인정학문단위 있는 학과): T1만(T2~T4 제외), 주저자만.
```
소프트웨어 컨퍼런스
- T1 주4편
('22, '24, '25)
```
AW=T1이면 소프트웨어, AX=T1이면 정보통신. **겹치면(둘 다 T1) 소프트웨어**로.

**탑티어**: Top-tier→"Top", 2nd-tier→"2nd". 학과단축명+tier+주N편+연도.
```
통계 Top 주1편('24)
통계 2nd 주1편('24)
```
학과단축: 통계학과→통계, 문헌정보학과→문헌정보, 기계공학부→기계공학(학부$→학).

**형식**: 비고 셀(연구역량표 마지막열, rowSpan2)에 여러 문단(줄)으로. 연도=게재년 뒤2자리 "'YY", 편수=논문수(연도는 중복제거). HCP 주저자>0이면 "HCP 주N편" 추가. 추출기 `bigo_lines()`가 생성→config `비고_lines`, 빌더 `fill_bigo_cell()`가 채움. [[gyoinhyeop-eval-table-2baesu]]
