교인협 자료의 **학과 심사 의견(장점/단점)** 원천은 `2027 정시채용 2단계 지원자 평가의견 취합_통합_260618_추천반영.xlsx` **심사결과 시트의 FI~JR열 = 연구발표_N_심사의견 + 인성평가_N_심사의견**(심사위원들이 직접 쓴 심사평)이다.

- **넣으면 안 되는 것**: `학과_추천의견`(OP열=[405]/컬럼 OP)·`학과_회의록요지`([406]). 이건 추천서/회의록이고 '1순위 추천', '핵심 인재로 최우선 추천' 같은 추천 문구가 들어감. 학과심사 의견에 이 문구가 섞이면 안 됨.
- 초기 SIMSA(_opinions_*.py)는 상당수가 추천의견을 요약해 넣은 오류가 있었음(장점뿐 아니라 단점도). 예: 물리 이성묵 장점 전체가 추천서 문구였음.
- FWCI/전공적합 심사의견(FI 이전 컬럼)이 아니라 **연구발표+인성(FI~JR)** 기준. 심사의견이 전부 긍정이면 단점은 "특기할 만한 단점은 제시되지 않음".
- **합성 규칙**: 심사의견 원문에 있는 내용만, 없는 말 지어내지 않기([[synthesis-accuracy]]). 강조는 문장 단위(핵심 절 전체, 키워드 포함)로 «»([[gyoinhyeop-formatting-charpr]]).

**진행 상태(2026.7.15 기준)**: 5.최종자료 파일명 번호 기준 2~8번은 사용자가 직접 재작성(문서만; config는 옛 상태라 검증 시 불일치로 뜸→재빌드 금지). 9번(물리)은 보류. 10~24번(21명)은 FI~JR 기준으로 재작성 완료·검증 0건.

**Why:** 사용자가 "학과심사 의견에 학과 추천의견 넣지 마, FI~JR에서 가져와야지"라고 명확히 지적. 매핑 검증(config→문서)만으로는 '내용 출처'가 틀린 걸 못 잡는다([[hwpx-text-extraction-pitfall]]).
