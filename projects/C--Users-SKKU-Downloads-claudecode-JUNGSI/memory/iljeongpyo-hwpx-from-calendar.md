`2027_정시채용\10_교원인사협의회_임용/06_일정표`의 (1~10일차) 교원인사협의회 일정표_당연직.hwpx는 **[[calendar-view-source-of-truth]]**의 `면접_달력뷰(평정반영)` 시트가 정답. 초안은 구버전이라 폐기하고 표1(일정표)을 전면 재구성했다(빌더: scratchpad/iljeong/_cal_itin.py→itin.json, _build.py, _eval.py).

**달력 열매핑**: C~L열(2~11)=1~10일차, 3행=날짜, 하단40행+는 메타(무시). 셀=시간범위/대학/분야([상시]·[정시]태그, 무태그=정시)/①②③④시간지원자/참석모드. 학과는 달력에 없음 → `분야정의` 시트(정시 25분야, 접두매칭)로, 상시는 대학+분야 추정.

**양식 규칙(1일차가 승인 기준)**: 표1 7열(대학|학과|채용분야|채용구분|성명|시간|비고). 정시=분야셀 안에 '(초빙세부내역)' 문단, 상시=분야열 분할(분야명 bf18 아래점선 / '[Scival 연구자 정보]' bf17 위점선; 단 1행 상시는 한 셀 2문단). 각 블록 끝 <평정>행. 대학셀=연속 동일대학 그룹 병합(점심/Break가 끊음), 구분셀=그룹내 동일구분 병합. **마지막 블록=상하 굵은 박스**(bf19/20/10/11/15/16, 상시는 bf21~24 신규). 표0 면접위원 가운데줄=header charPr strikeout→NONE. 비고에 참석모드(온라인ZOOM/오프라인) 병기. 성명 전부 빈 TBD 슬롯·별도(상시)이름·원테이블·VIP·예비·캠승위 제외.

**header 전략**: 각 파일 고유 header 유지(표0 면접위원 구성이 날짜별로 다름) + 1일차 도너 스타일(bf8~24, charPr7~12·26, paraPr20·27~32)만 merge_header로 병합.

주의: 표0 면접위원 구성은 초안값 보존(관리자 설정). 달력 하단 고정직표와 불일치 소지 있어 사용자 확인 필요(예: 6일차 자부총장). 4일차 'AI기반 생물정보학'은 달력에 대학·태그 없어 공란·정시 처리.
