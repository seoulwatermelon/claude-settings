When drafting any email for the user, do NOT use tables (markdown or otherwise). The user copy-pastes drafts into an email client and tables do not paste correctly.

**Why:** Tables break / don't copy-paste into the user's mail client.

**How to apply:** Present comparative or per-item info (e.g. score changes, schedules) as prose or numbered/bulleted lists instead of tables. This applies to email bodies specifically; standalone Excel/Word deliverables can still use tables.

**Exception (2026-07):** The 합격자 최종면접 안내메일 (final-interview invitation to successful candidates) DOES use a table — the user's official sample formats the applicant's info (초빙분야·성명·이메일·연락처·면접방식·일자·면접시간·대기장소·소요시간·비고) as a table, and the user explicitly asked for it. Use a 2-column vertical table (항목 | 내용, shaded label column) rather than the sample's wide 10-column horizontal layout, since vertical pastes cleaner. So: no-tables is the default, but follow the official sample when one uses a table. Related: [[reviewer-comm-templates]] 격식 문어체 guidance.
