교인협 자료 1페이지 **정시채용 평가결과표**는 면접 대상자만이 아니라 **해당 분야 모집인원의 2배수 순위 안 인원 전원**을 적는다(성적순위 기준).

- **모집인원**: 2027_학과추천_회신현황표_260618 E열. 2배수 = 2×모집.
- **후보 목록**: 추천반영(2단계 평가의견 취합)에서 성적순위 ≤ 2배수인 전원. 미추천자도 포함.
- **학과추천 열**: 회신현황표 K(1순위)/L(2순위)/M(3순위↑)에 이름 있으면 1/2/3…, 없으면 **미추천**. 공동1순위는 둘 다 1.
- **면접진행 열**: 추천된(K/L/M에 있는) 전원 **○**, 미추천만 **×**. (일자별명단 본부의견 ○/△/× 아님)
- **미추천자 정보**(성명·성적·출신학교·현직): 합격자명단에 없으니 **추천반영**에서 가져옴.
- **2페이지 후보자 상세분석**: 추천된 사람만(미추천 제외).

배치1(문헌정보·미디어·통계·기계)은 전부 모집1·2배수2·둘 다 추천이라 표 행은 그대로고 면접진행만 전원 ○. 미추천 포함 2배수 확장 로직(행 추가·추천반영에서 데이터)은 국어국문(인원축소) 등 해당 분야에서 구현 예정. [[project_jungsi_overview]] [[gyoinhyeop-retire-chobing-marking]]
