강조·인용 구절을 표시할 때 **`「」`(홑낫표) 대신 `' '`(작은따옴표)**를 쓸 것.

**Why:** 사용자가 `「」` 기호를 `' '`로 바꿔달라고 요청함.

**How to apply:** 채팅 메시지에서 핵심 구절을 강조 표시할 때 `'적합성이 높음'`처럼 작은따옴표 사용. 참고로 교인협 hwpx 문서 내부의 강조는 볼드+밑줄(charPr)이며 괄호 기호는 넣지 않음 — 빌드 시 `«»`는 볼드밑줄로 변환·제거되어 출력엔 안 남음. [[gyoinhyeop-retire-chobing-marking]]
