`2027_정시채용\09_면접일정조율/2027 상시,정시채용 일정표_*.xlsx` 의 면접 일정.

- **면접_달력뷰(평정반영)** = 확정 시간표(source of truth). 분(minute) 단위 시간축 + 평정/점심 블록 + 분야셀(대학/분야/①②③ 지원자). 10일 열: B=7/27,C=7/28,D=7/30,E=7/31,F=8/3,G=8/4,H=8/5,I=8/6,J=8/10,K=8/11.
- **면접_달력뷰** = 위에서 '평정/점심' 뺀 **분야별 정리본**. 절대 손으로 옛 내용을 고치지 말고 평정반영에서 세션을 **추출해 재구성**(`_rebuild_calendar_view.py`). 세션 시작시각(텍스트 'HH:MM~' 또는 A열 시각)으로 시간축 행 배치. 각 열에서 시작시각은 유일 → 충돌 없음.
- 검증: evaluator가 두 시트 세션 집합을 문자 단위 1:1 대조(52세션). 사용자는 "100% 맞을 때 마무리" 요구 → 재구성 후 반드시 대조.
- **openpyxl `delete_cols`는 병합셀을 안 옮김**(옛 좌표에 남음). 열 삭제 대신 시트 재구성하거나 병합을 수동 재설정할 것.
- 일자별 참석자 표 디자인: 면접_달력뷰 원본(제목 fill FF2E75B6 볼드흰, 헤더 FFDDEBF7, 데이터 FFE2EFDA 초록). 두 시트 동일 적용. 고정직 열은 D:K 병합.
- 잔재 주의: 옛 면접_달력뷰는 12날짜열(M열까지) → 재구성 시 A~K(1~11) 밖 L·M열 잔재 반드시 제거.
- 고정직 참석 규칙은 [[gyoinhyeop-hakbudaehak-4slot]]와 별개, decision-calendar-pattern 스킬 참조. 겸직: 최훈석=부총장(인문)=학부대학장, 권영욱=부총장(자연)=성균융합원장(동일인물, 학장인 분야에선 고정직서 제외).
