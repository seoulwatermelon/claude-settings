교인협 **학부대학**(그룹1, 의사소통영역 통합교육(글쓰기/스피치))은 유일하게 **모집 2명·1~4순위 4명 추천**이라 다른 분야(2배수 2명)와 구조가 다르다. 후보 4명 전원 **국제A 0편**.

- **4슬롯 확장**: `_expand_slots.py` — 2슬롯 템플릿을 후보 수만큼 복제(상세구역·종합의견 블록·논문상세·1페이지 표 행: 평가결과 1행/연구역량 2행/2단계 1행/외부의견 4행·학과심사 3문단). 빌더가 `len(CANDS)>2`면 자동 호출.
- **국내 위주 표**: `_domestic_tables.py` — 주요지표를 `국내 전체(A+B)/국내A(성균학술목록)/국내B(그 외 KRI)`, 생산성을 국내A·국내B×전체·주저자로 재작성. 영향성(JIF 구간, 국제A 기준 전부 0)은 표째 제거. config 플래그 `국내위주: true`.
- 퀵패스는 xlsx(`정시_학부대학_이름.xlsx`), `_xlsx_qp.parse()`에 `국내_지표`·`국내B_생산성` 추가됨.
- 대학명=학과명이면 파일명·문서제목에서 **중복 제거**(`1. 학부대학_분야.hwpx`, `학부대학 (분야) …`).

**이때 고친 기존 빌더 버그 3건** (기존 18개 중 실제 피해는 ②의 1건뿐, 21번 헬스케어 초빙사례 누락 → 수정 완료):
1. `KRI` 문단 삭제가 **표를 감싼 문단째** 지움 — `.//hp:t`가 표 안 글자까지 읽음. → 최상위·표없는 문단만 대상.
2. 참고자료(초빙사례·퇴임)를 **문단번호 188/193 하드코딩** — 슬롯 확장 시 어긋남. → `▮제목` 다음 줄을 내용으로 탐색.
3. 논문상세 제목을 **샘플 이름(김병철/하경호) 매칭**으로 배정 — 복제 슬롯은 전부 '하경호'라 같은 후보가 됨. → 최상위 `▮바이오로보틱스…` 문단을 **문서 순서**로 배정.
   또한 `_locate`의 제목표 판정을 `학과 \d+순위` 정규식으로 일반화(3·4순위 인식).

**Why:** 인덱스 하드코딩과 샘플 이름 매칭은 슬롯 수가 바뀌면 조용히 깨진다([[mistake-overbroad-rebuild]], [[hwpx-text-extraction-pitfall]] 참고). 검증은 표/문단 인덱스가 아니라 **내용 기준**으로.
