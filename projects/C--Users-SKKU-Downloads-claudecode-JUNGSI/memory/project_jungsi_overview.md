## 업무 한 바퀴 (`JUNGSI\<연도>_정시채용\`)

번호가 일처리 순서다. 폴더 구조 자체는 [[jungsi-folder-structure]] 참고.

1. `01_초빙세부내역` — 학과에 TO 안내 → 세부내역 회신. 한영통합 엑셀/HTML 산출
2. `02_공고_모집요강` — 공고문·모집요강·공문 HWPX 생성 (단과대학별)
3. `03_원서접수_경쟁률` — 지원자격·경쟁률 집계
4. `04_심사위원_추천_제척` — 학과 추천서 접수 → 제척검증 ([[jecheok-verification-patterns]])
5. `05_서류심사` — 합격자 선발·안내 → 합격자 서류 제출 접수
6. `06_연구력검증_GPR_DPR_PR` — GPR·DPR·PeerReview
7. `07_2단계심사` — 학과심사 계획 → 발표회 → 결과취합 → 점수검증
8. `08_원테이블_결과보고` — 학과추천 취합 → 원테이블 → 2단계 결과보고
9. `09_면접일정조율` — 총장·부총장·학장 일정 → 면접 시간표
10. `10_교원인사협의회_임용` — 면접 → 임용심사 → 이사회 → 발령·직급산정·계약

## 단계를 넘나드는 것

- **우수학술지·Top-tier 목록**(`00_공통\01_우수학술지_Toptier목록`)은 4·6·7·10단계가 공통으로 참조한다.
  해마다 새로 만들지 않고 갱신해 쓴다.
- **학과 건제순 기준표**(`00_공통\02_학과_건제순_기준표`)는 명단·보고서 순서를 정할 때 쓴다.
  가나다순 아님.
- **교원확보율**(`01_교원확보율`)은 연도와 무관한 상시 업무지만, 학과별 TO 배정의 근거라
  1단계보다 앞선다. [[gyowon-hwakboyul-automation]]

**Why:** 학과 데이터가 여러 단계에 중복 하드코딩돼 있어, 임용쿼터나 학과 신설·폐지가 생기면
여러 단계를 함께 고쳐야 한다.

**How to apply:** 학과 추가·삭제 시 1·2·4·6·7단계와 `00_공통` 기준표를 모두 확인할 것.
