`2027_정시채용\10_교원인사협의회_임용/07_평정표_서명본/{N}일차.pdf`는 스캔 이미지(텍스트 0). 각 장 = 지원자 1명 × 심사위원 1명. 상단 인쇄=채용분야·면접대상자 성명, 중단=평가점수표, 하단="심사위원 [수기이름] (서명)".

**평정등급**: 평가점수란은 A(탁월)·B(우수)·C(보통)·D(미흡)·E(매우미흡)·유보 중 택일이고, **심사위원이 고른 칸 안에 직접 서명**한다. 서명이 있는 열 = 등급. 학장은 서명 대신 'O'(동그라미)로 표시하기도 함(영문서명·도장인 경우도 있음).

**심사위원 7명**: 총장 유지범 · 자과캠 부총장 **권영욱**(성균융합원장 겸) · 인사캠 부총장 최훈석 · 기조처장 유필진 · 대학원장 이내응 · 교무처장 배상훈 · + 해당 대학(원) 학장. 학장↔대학 매핑은 `2027_정시채용\02_공고_모집요강/2027_교수초빙_회신체크리스트_v2`(비상연락처 시트).

**겸직·특례(중요)**: ① 성균융합원장=자과캠부총장 **권영욱** → 성융 지원자는 6명 완비(학장란=◎). ② **학부대학장=인사캠부총장 최훈석**(8일차) → 학부 지원자 학장란=`겸`, 6당연직+의무부총=7명. ③ **의무부총장=이우용**은 8일차만 참석(학부·의과 평정) → **의과대학은 8명 평정**(6당연직+의과학장 이준행+이우용), 의과 지원자 8/8. 다른 날은 의무부총장 불참(평정표 없음). 서명 '이우홍'처럼 보이나 실제 **이우용**.

**면접점수 산출(회의록용)**: A=5·B=4·C=3·D=2·E=1 평균(유보·무·✕·-·◎·겸 제외). **유보수>점수개수면 '유보'**로 결론, 아니면 평균값. 예: 이성묵 31/7=4.43, 전용현 35/8=4.38(이우용 포함), 유보다수는 '유보'. 평정표 xlsx에 검증열(점수치환·총점·면접점수 엑셀수식) 있음.

**판독 파이프라인**(scratchpad/pyeong): pymupdf(fitz)로 dpi150 렌더 → 한 줄에 [성명 크롭 | 평가점수 마크행(열 구분선·A~유보 라벨 그림) | 서명 크롭]을 가로로 합친 combo 몽타주(10~16장/이미지)로 육안 확정. 잉크농도 자동감지는 배경노이즈로 부정확(특히 유보/E 오탐) → 반드시 육안. 학장 O표시·영문서명·애매건은 dpi200 개별 확대. 페이지 크기가 다른 별도 스캔(6일차 p43~45 김성현: 1930x2506 등)은 고정좌표 크롭 실패 → 비율좌표로.

**관찰**: 당연직이 각 분야 한 후보엔 실등급, 다른 후보엔 전원 '유보'를 준 경향. 산출물 = `2027 정시채용 평정표 제출·평정등급(1-9일차).xlsx`(제출/기대·등급·상태·비고 + 검증열 + 범례시트). 1~9일차 전수 교차검증 완료(정정 4건: 김홍식/배상훈 유보, 김석우/배상훈 유보, 박경현 최훈석·이내응 무).

**회의록**: `9. 회의록/붙임1…회의록.hwpx`가 양식(작년 예시 채워진 것). 분야별 7행 블록(6열 표): 시간/구분/일차·대학/학과·채용분야/대상자·참석위원·불참위원·면접점수·회의내용. 생성기 scratchpad/pyeong/gen_minutes.py(원본 head/footer 재사용+블록 XML 생성). 참석=평정표 제출자, 불참=미제출+부총장(의무 8일차 제외). 회의내용=합격→제청/유보·불합격→유보 결정문(양식대로)+BD·BE 코멘트를 양식체로 다듬어 작성(원자료 메모라 지어내지 말고 충실 요약). 코멘트 출처=`합격자명단_v2` BD(56)·BE(57)열(단 상시·정통 등 20명은 명단에 없어 공란). 기록자/확인자는 원본값 유지.

주의: 수기 판독이라 유보·미제출·상이건은 원본대조 권장. 편철오류 발견(6일차 끝 p46/47=1일차 최화섭·김홍식 박두선분 중복, 김홍식/박두선 등급이 B/유보로 상이). 관련 [[calendar-view-source-of-truth]].
