2027 정시채용 2단계 설문평가(외부 심사위원용)의 문항·답변 코드. 통합파일의 설문 `답변`(1~5)을 라벨로 변환할 때 사용. 코드 방향 검증 완료(통합 데이터 = 설문지 이미지 일치, 1=첫 옵션).

- **문항1 — "세계 수준의 연구자로 성장할 잠재력/가능성"**: 1=매우 높음, 2=높음, 3=보통, 4=낮음, 5=매우 낮음
- **문항2 — "현재 연구력 및 수준"**: 1=세계 수준, 2=국내 상위, 3=보통, 4=국내 하위, 5=매우 낮음
- **문항3 — "채용 여부"**(+사유 텍스트): 1=매우 적극채용, 2=적극채용, 3=보통, 4=채용보류, 5=미채용

**How to apply:** VIP 보고용 「일자별 대상자 명단」(작년 양식 HWPX)의 종합의견 끝부분 "▸외부 심사위원 채용의견 — 잠재력/가능성: …, 연구력 수준: …, 채용여부: …"에 위원별 답변을 라벨로 변환해 명수 집계(예: "높음 2명, 보통 1명"). 통합파일 설문 데이터는 위원×문항 행으로 저장됨. 관련: [[email-no-tables]] 아님 주의(이건 보고서/표 허용). 작년 양식 파일: (원테이블)…일자별 대상자 명단.
