보고서 수정 지시는 지시문의 동사를 그대로 이행한다. 기존 내용을 덜 건드리려고 덧붙이기·주석 한 줄로 축소하지 않는다.

**Why:** 2026-11-09 팀장 피드백 5건을 반영한 `_261109.hwpx`를 사용자(교원인사팀 승주완 책임)가 2026-11-10에 보고 "내 주문들이 다 적용이 잘 안 된 것 같다"고 했다. 사용자가 항목별로 짚지는 않았고, 아래는 내가 렌더본을 지시문과 대조해 찾은 어긋남이다(내 해석).
- "배경을 **다시 작성**" → 기존 2항목을 두고 3번만 추가했다. 전면 재작성이 맞다.
- "표 밑에 → 화살표로 **여기서 말하고 싶은 바**" → 표 위 산식을 그대로 반복한 3줄을 넣었다. 결론 한 줄이 맞다.
- "평균 명수로 임용 시, 10% 초과 임용 시 **시뮬레이션 보여주기**" → 10% 초과를 ※주석 한 줄로만 처리했다. 표에 시나리오 열로 나란히 보여줘야 한다.
- 문장이 길어 줄이 넘어가거나 글자가 눌렸다.

**How to apply:**
- 지시마다 "무엇을 어떻게 바꾸라는 동사인가"를 먼저 적고, 결과물에서 그 동사가 눈에 보이는지 렌더본으로 대조한 뒤 보고한다.
- "보여주기"는 표·그림으로, "써주기"는 지정한 문구로, "다시 작성"은 해당 절 전체를 새로 쓴다.
- 화살표(→) 줄은 표의 결론만 담고 숫자 산식은 반복하지 않는다.
- 사용자가 직접 넣은 수치를 빼게 되면(예: 배경의 전교 현원, 학기별 시계열) 완료 보고에 무엇을 뺐는지 밝힌다.
- 범위: 이 사용자의 행정 보고서 수정 작업 전반. 표 간격·열 폭 등 사용자가 한글에서 손본 서식은 계속 보존한다([[professor-lab-space-report]]).
