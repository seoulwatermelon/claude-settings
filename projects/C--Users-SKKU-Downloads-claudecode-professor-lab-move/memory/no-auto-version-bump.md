수정할 때마다 `_v2`, `_v3`처럼 새 파일을 만들지 않는다. **현재 작업본 파일에 덮어쓰고**, 사용자가 "버전 새로 파라"고 말할 때만 새 파일명을 만든다.

**Why:** 2026-11-10 하루에 `_261110` → `_v2` → `_v3`를 연달아 만들자 사용자(교원인사팀 승주완 책임)가 "버전 계속 업하지 말고 v2로 해, 내가 버전 새로 파라고 하기 전까지는"이라고 지시. 그때 v3 내용을 v2로 옮기고 v3 파일은 없앴다.

**How to apply:**
- 교수연구실 보고서의 현재 작업본은 `…부족 전망_261110_v2.hwpx`. 이후 수정은 이 파일에 덮어쓴다([[professor-lab-space-report]]).
- 덮어쓰기 전에 사용자가 그 파일을 한글에서 직접 고쳤는지 확인한다(내가 마지막으로 만든 파일과 바이트 비교). 고쳤다면 사용자 편집본을 풀어서 그 위에 수정한다 — 내 작업 폴더의 옛 사본으로 덮어쓰면 사용자 편집이 사라진다.
- 사용자가 한글에서 파일을 열어 둔 상태면 덮어쓰기가 막힐 수 있으니, 실패하면 닫아 달라고 알린다.
- "건드리지 말고 새 버전으로"라고 명시한 원본(`_261102` 등 사용자가 지정한 기준 파일)은 여전히 덮어쓰지 않는다.
- 범위(내 해석): 이 사용자와의 문서 작업 전반에 같은 원칙을 기본으로 삼는다.
