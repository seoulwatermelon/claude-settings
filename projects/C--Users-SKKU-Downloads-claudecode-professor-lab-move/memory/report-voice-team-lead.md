보고서는 **제목(결론·핵심 수치) → `-` 메시지 줄 → 표** 순서로 쓰고, 문장은 명사형 보고서체로 한 줄에 맞춘다. 전문은 전역 규칙 `~/.claude/rules/common/report-voice.md`와 hwpxskill SKILL.md "보고서 문체·구성 규칙"에 옮겨 두었다(2026-11-10). 이 메모리는 그 근거가 된 발언을 기록한다.

**Why — 누가 언제 무엇을 말했나(모두 2026-11-10, 교수연구실 공간 보고서):**
- 팀장(사용자 전언): "숫자는 다 들어가 있는데 무슨 말 하는지 친절하지 않다. 항상 표와 수치로 파트를 마무리하고 하고 싶은 말이 안 쓰여 있다" / "휴먼 터치가 필요하다" / "어색한 표현이 많다 — '2031년에야 가능'의 '에야'는 보고서 투가 아님" / 산식 줄에 대해 "너무 자세하다, 윗분들이 일일이 계산해야 하느냐".
- 사용자(승주완 책임): 내가 모든 표 아래에 `→` 를 달자 "매번 하는 건 아닌 것 같다. `-` 에 말하고 싶은 바를 써 놓고 표나 도식으로 가는 게 맞다. 결론을 내고 싶은 특정 경우에만 화살표" / "459실에 공동연구실·비전임이 어떻고 하는 구차한 변명 말고 423명에 맞춰 표를 만들면 된다" / 배경 근거가 "어리둥절하다, 근거 수치는 붙임에 표로" / "구어체 말고 보고서 투로" / "밑에 부가설명 줄은 1줄만 인정" / Ⅳ의 "1, 2번이 같은 말을 다르게 하니까 헷갈린다".

**사용자가 직접 고친 최종본에서 읽은 것(내 관찰):** 배경은 `1.` 줄 위주에 부가 줄은 1번에만 1줄, 나머지는 제목 끝 괄호로 처리. 제목을 "항목 : 결론" 꼴로 쓰고 결론 부분을 굵게+밑줄. 그림은 제목 바로 아래로 올리고 설명 `-` 줄을 그림 뒤에 둠. 내가 단 `※` 주석 대부분을 지움. "비는"→"발생하는", "신규임용시"처럼 한자어 명사형으로 다듬음. 근거 표를 붙임1로 올려 인용 순서에 맞춤. 전체를 8쪽에서 6쪽으로 줄임.

**How to apply:** 새 보고서 초안부터 전역 규칙대로 쓴다. 초안을 낸 뒤가 아니라 쓰는 단계에서 ①절마다 제목에 결론이 있는지 ②표 앞에 `-` 메시지가 있는지 ③본문에 계산식·기호 나열·구어가 없는지 ④기간이 다른 숫자를 나란히 놓지 않았는지 ⑤같은 내용을 두 항목이 다르게 말하지 않는지 점검한다. 관련: [[apply-report-feedback-literally]] · [[hwpx-direct-edit-lineseg-and-render]] · [[no-auto-version-bump]] · [[professor-lab-space-report]]
