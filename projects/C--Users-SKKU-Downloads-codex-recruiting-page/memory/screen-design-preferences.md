사용자가 2026-11-11에 화면을 보고 직접 말한 것 (지금도 유효):

- 'SKKU 교원채용 All-In-One' 이름, 성대 로고, 슬로건(인류와 미래사회를 위한 담대한 도전)은 사용자가 만든 정체성 요소다. 없애지 않는다(보여 주는 방식은 바꿔도 됨).
- "생각보다 너무 복잡하다. 보기 쉽고 직관적이어야 하고, 처음부터 모든 게 확 오면 안 된다."
- 제목은 질문형이 아니라 보고서처럼 결론과 숫자("2027학년도 채용 진척 : TO 배정 75명 중 임용 확정 3명").
- 경영진 화면은 전년 대비 채용, 연구력, 결정할 건에서 출발. 너무 적으면 "참고 안 한다" — 현황판도 함께.
- 표보다 차트·그래프. '학과별 분야지도'는 마인드맵.

2026-11-16 사용자가 "기존의 관습과 경로의존성을 타파하고 … 압도적으로 개쩌는 디자인, 통계자료도 같은 방식으로, 기획은 Fable로"라고 지시 → Fable이 기획한 「한 장」(화면이 곧 한 장짜리 보고서)으로 전면 개편. 기준 문서: `docs/superpowers/specs/2026-11-16-design-overhaul.md`.
- 사이드바 대신 위쪽 머리띠, 미색 종이 바탕, 강조색은 성대 녹색 하나, 금색=지금, 빨강=멈춤만.
- 카드 상자 대신 짧은 머리선 + 번호 붙은 절, 큰 숫자는 화면당 최대 3개, 입력 폼은 접어 둔다.
- 칸반 대신 진행선(노선도), 차례는 모양(● 학과 ■ 본부 ◆ 경영진)+글자.
- 그림은 손으로 만든 SVG/HTML(components/viz). 이 개편에서 사용자가 전에 고른 ztd-charts를 걷어냈다(내 판단, 완료 보고에서 알림).

2026-11-17 사용자가 관리자 대시보드 참고 화면(Veyla 스타일)을 보여 주며 "장치만 골라 쓰자" — 바탕(「한 장」)은 유지하고 장치만 차용: 직전 대비 줄, 기준선 시뮬레이션, 타일 격자+옆 상세, 실선·점선 비교, 진한 대기 덩이, 결과 3단 칸 (c9bac96).

**Why:** 사용자는 만든 사람이 아니라 쓰는 사람(학과장·경영진) 관점에서 본다. 기능을 다 넣은 화면에 실망했고, 흔한 관리자 대시보드 모양을 벗어나길 원했다.

**How to apply:** 새 화면·수정은 「한 장」 문서의 토큰·부품(PageHeader eyebrow/message, Card no, HeroStat, TurnTag, StageRail, components/viz)을 따른다. 정체성 요소와 큰 방향을 다시 바꾸기 전에는 묻는다. 관련: [[rebuild-purpose-and-direction]]
