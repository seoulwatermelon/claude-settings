학생부종합 평가의견 셀은 한 줄로, 항목을 " / "로 구분해 쓴다("- " 글머리표·줄바꿈 금지). 실제 평가자 메모처럼 짧고 쉽게 쓴다.
- 맨 앞 항목: 주요교과 1→3학년 추이를 상승세/하락세/보합세로 적시하고 괄호에 학년별 등급 기재(예: "주요교과 상승세(1학년 3.13 → 2학년 2.40 → 3학년 1.90등급)"). 상승 폭이 크면 "인상적" 표현 추가.
- AI 말투 금지: "꾸준한 나눔 실천"류 상투 문구 삭제, 실제 평가자 메모체(짧은 명사형 종결)로 쓰고 지원자마다 표현·어순을 불규칙하게 변형. 하위 30%는 추이·학업·약점 1~2개만 간략히(봉사 저시간은 항상 기재).
- 고교유형(과학고: 2학년까지만 성적 / 영재학교: 4.3 만점 평점)은 의견이 아닌 별도 열에 표시. 영재 평점은 높을수록 우수하므로 9등급으로 오독하지 말 것.
- 쓰는 것: 등급 수치(전교과·수학·과학), 학교 지표 수치(미적분 이수비율, 언매 비율, 교과 평균·표준편차), 봉사 시간.
- 금지: 백분위·순위 표현(모집단위 상위 X%, 교내 z백분위, 전형 내 N위, 동일교 N명 중 k위), 세특·창체 글자수, "▶ 종합/강점/보완" 요약줄(다른 열에 있는 정보), 장황한 문장, 고교등급제 암시(특목고·자사고 등).

**Why:** 사용자가 백분위·순위 표현은 "위험하다", 글자수는 "너무 짜친다", 요약은 앞 열과 중복이라며 직접 수정 지시함 (2026-09-29).
**How to apply:** 입학사정 의견 생성 시 처음부터 이 형식으로 작성. 강점 파랑/약점 빨강 서식은 유지. 평가자 100점까지 반복 요청 시 스킬 기본 5회 제한보다 사용자 지시 우선.
