`06_Hybrid_260918\[초안] 핵심 연구진 관리·육성 실행 방안(상세).hwpx`는 **사용자가 한글에서 직접 고치고 있다.** 2026.9.22. 기준 7쪽(5章 육성 경로)까지 수정 완료, **6章 소요 예산부터는 미수정.**

**Why:** 내 빌더 `_scripts\build_detail.py`로 다시 찍으면 사용자 수정이 전부 날아간다. hwpx(한글 저장본 약 100KB)가 유일한 최신본이고 빌더는 구판이다.

## How to apply

1. **작업 전 반드시 `_backup\`에 사본을 뜬다.**
2. 수정은 **`Contents/section0.xml`에 문단을 직접 끼워 넣는 방식**으로 한다. 한글 저장본은 `paraPrIDRef="0"`으로 평탄화되어 있고 들여쓰기는 **앞 공백**으로 처리된다.
   - `□` = `charPrIDRef="8"`, 앞 공백 2칸 / `-` = `8`, 3칸 / `※` = `12`, 4칸 / `*` 각주 = `12`, 4칸
   - `<hp:linesegarray>`의 `vertpos`는 한글이 열 때 재계산하므로 0으로 둬도 된다
   - 재패킹 時 `mimetype`·`version.xml`·`PrvImage.png`는 **무압축(compress_type=0)** 유지
3. 줄 폭은 `skku_report`의 `em()`/`cap()`으로 사전 실측한다(15pt 30.84em / 13pt 35.58em).
4. 사용자가 **"다른 내용은 건드리지 말라"** 고 하면 기존 넘침·오류도 손대지 말고 **보고만** 한다.

## 사용자 편집 경향 (반영할 것)

- 종결을 `~함/~임`에서 **명사형으로 더 짧게** 끊는다(「…구축」, 「…차별화」)
- **章 제목에서 `①②③` 제거** — 「2. 선제적 관리 — 핵심 연구진 Tier 1」
- 확정 안 된 수치는 **`추산필요`**로 비워 둔다(포상 10종 인원·건수·예산)
- 표에서 불필요한 열을 지운다(판정 단계別 대응의 「인원」 열, Tier別 집중 지원 표 전체)
- 작성자명을 머리글에 넣는다(`교원인사팀 2026. 9. 22.(화) 승주완`)

**설계 원칙 — 다음 판본에서도 지킬 것**
- **章2의 □ 4개와 축 4개가 1:1.** 축을 늘리면 章2에 문제 □를 먼저 세운다.
- **□만 읽어도 흐름이 이어져야 한다.** 근거를 `l2`에 두면 □만 훑는 임원에게 안 보인다(3-2 타대학 근거가 그래서 □로 올라갔다).
- **育成 3축은 병렬**이다. 축 사이에 이음매 문장을 넣으면 앞 축이 뒤 축의 전제처럼 읽혀 구조가 왜곡된다. 3-1 → 3-2만 다리가 필요했는데, 3-1이 부정(「물량 경쟁으로는 방어 불가」)으로 끝나기 때문이다.
- **「타대학 있어? 근거는?」이 모든 축에 따라붙는다.** 네 축 모두 국내 사례를 갖췄다.

**주의할 함정**
- **THE 연도 축이 자료마다 다르다.** 발표자료 4쪽은 **발표연도**, 6·25쪽은 **판번**이라 정확히 1년 어긋난다. 판번 기준 실값은 `'22 122 / '23 170 / '24 145 / '25 102 / '26 87 / '27 68`(pptx 도형 x좌표로 확정). 표에 공유 연도 헤더를 쓰지 말고 **행마다 자기 기간**을 달 것.
- **'27판 68位는 '26.9.30. 엠바고** — 그 전에는 대외 인용 금지.
- 상위 2% 218名은 **3-2와 3-3에 함께** 적용된다. 숨기지 말고 註로 밝힌다.
