`02_보고서\` 보고서는 마크다운 원본에서 **hwpx로 빌드**한다(hwpxskill 활용). 기준 양식은 `01_원본자료\[양식] 회의자료 작성 양식.hwpx`.

**양식 규격** (마크다운 상단 주석에 명시):
- 용지: A4 세로, 여백 위/좌/우 20mm, 아래 15mm
- 제목: HY헤드라인M 22pt, 글상자 테두리선 0.3mm
- 대분류: HY헤드라인M 16pt (I. II. III.)
- 본문1: 휴먼명조 15pt (1. 2. 3. — 두 칸 들여쓰기)
- 본문2: 휴먼명조 15pt (1) 2) 3) — 세 칸 들여쓰기)
- 본문3: 휴먼명조 14pt (① ② ③ — 네 칸 들여쓰기)
- 참고: 한양중고딕 13pt (※ — 네 칸 들여쓰기)
- 표: 휴먼명조 14~12pt

**버전 관리:** 메인 보고서는 v1→v8까지 반복 진행됨. 최신본만 `02_보고서\` 루트, 이전본은 `02_보고서\_archive\`. 빌드 스크립트는 `04_빌드스크립트_보관\`(gen_v3~v5.py 등).
