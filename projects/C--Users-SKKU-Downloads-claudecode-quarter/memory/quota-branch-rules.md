한 행정소속코드가 둘 이상의 채용분야로 갈리는 경우:
- 경영전문대학원 = 교무소속코드로 GSB / 경영학+글로벌경영 구분. 교무소속코드가 '경영전문대학원'인데 실제 GSB인 교원은 전년도 확정값 승계로 GSB 유지, 신규자는 예외처리로 지정(예: 김도윤, 엔리크훈케데포르투니).
- 의학과 = 의대소속코드='기초의학'이면 의학과(기초), 그 외 의학과(임상).
- 그 밖에 자동 판별이 안 되는 갈래(약학과 1601/1602 등)는 전년도 다수결을 기본값으로.

**Why:** 사용자가 명시적으로 합의한 규칙. 교내번호 같은 부수 신호가 아니라 교무소속코드가 공식 기준.

**How to apply:** 매핑표는 행정소속코드 1행이 아니라 **나올 수 있는 채용분야를 전부 한 행씩 펼쳐서** 보여줄 것 — 규칙이 코드 안에 숨어 있으면 사용자가 검토할 수 없다.
전년도→최신 갱신 시 **행정소속코드가 바뀐 사람은 반드시 관리자 수동 확인**을 거쳐야 하므로, 확인대상 자동 추출 + 확인대장 등록 전까지 검증 미통과로 막는 장치를 둔다.
