엑셀 결과물을 만들 때 계산 결과를 값으로 하드코딩하지 말고 반드시 수식(참조/COUNTIFS/INDEX-MATCH)으로 작성할 것.
원본 시트를 워크북 안에 그대로 넣고 계산 시트가 그 시트를 참조하게 만든다.

**Why:** 근거를 역추적해서 결재·감사 대응을 해야 하고, 후임자가 숫자의 출처를 확인할 수 있어야 함.

**How to apply:** ① 원본 붙여넣기 시트(가공금지) / 사람이 고치는 입력 시트 / 수식 계산 시트를 색으로 구분,
② openpyxl로 수식을 쓴 뒤 `win32com` 으로 Excel 재계산·저장해 값 캐시를 남기고,
③ 같은 로직을 파이썬으로 독립 계산해 엑셀 값과 대조하는 검증 스크립트를 함께 둔다,
④ 워크북 안에 자동 점검 시트(행수·합계·미매핑 건수)를 넣는다.
⑤ openpyxl로 쓴 MAXIFS 등 신함수는 Excel에서 #NAME? 이 되므로 SUMPRODUCT(MAX(...)) 같은 구식 대안을 쓸 것.
⑥ 다른 시트 셀을 그냥 참조하면 빈칸이 0으로 와서 날짜/문자 판정이 깨짐 → `=IF(원본="","",원본)` 로 감쌀 것.
