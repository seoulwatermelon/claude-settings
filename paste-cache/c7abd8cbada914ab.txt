# Agent Teams 실행 프롬프트

> Superpowers 계획(`docs/superpowers/plans/2026-03-18-recruiting-refactor-plan.md`)을 기반으로 실행하되,
> 아래 보완사항을 반드시 반영해줘.

---

## 보완사항 (Superpowers 계획에 누락된 것)

### 1. 사이드바 메뉴를 원래 요구사항 8개로 맞춰줘

Superpowers가 메뉴를 자체 재해석했는데, 아래 8개 메뉴를 **그대로** 사이드바에 만들어줘:

```
계정관리
한 눈에 보는 채용 원테이블
(DB)후보자 관리
(DB)관리자 페이지
후보자 검증
채용 진행
채용 완료
학과장 Action
```

Superpowers 계획의 세부 페이지(summary, allocation, progress, data-sheet, workflow, permissions, users)는 이 8개 메뉴의 **하위 기능이나 내부 탭**으로 배치해도 좋지만, 사이드바 최상위 메뉴는 위 8개를 유지해줘.

### 2. "후보자 검증 / 채용 진행 / 채용 완료" 3개 페이지 신설

이 3개는 Superpowers 계획에 빠져 있다. **반드시** 독립 페이지로 만들어줘.

각 페이지의 구조:
- **상단**: 채용 프로세스 흐름도/타임라인 (전체 단계가 보이고, 현재 단계가 하이라이트)
- **하단**: 해당 단계에서 해야 하는 일, 입력할 것, 확인할 것

지금 단계에서 완성할 필요 없고, **뼈대와 플레이스홀더**를 잘 잡아줘. 내가 후속 개발할 수 있게.

### 3. "학과장 Action" 독립 페이지 신설

학과장이 해야 할 액션들을 모아서 보여주는 독립 페이지. DEAN 역할 전용. 역시 뼈대까지만.

### 4. 로고 교체

`logo_SKKU_transparent.png` 말고 아래 둘 중 하나를 써줘:
- `logo_SKKU_black`
- `logo_SKKU_colored`

화면에 더 잘 어울리는 쪽으로 선택. 로그인 화면과 사이드바에 일관 적용.

## 팀 구성

이 프로젝트 리팩토링을 팀으로 진행해줘.
먼저 `CLAUDE_HANDOFF.md`와 현재 코드베이스를 읽고 구조를 파악해.
Superpowers 계획서(`docs/superpowers/plans/2026-03-18-recruiting-refactor-plan.md`)도 반드시 읽어.

### Teammate 1: 앱 프레임 & 라우팅
- Superpowers 계획의 **Chunk 1** (디자인 토큰 + 사이드바) 실행
- 단, 사이드바 메뉴는 위 8개 메뉴로 수정
- 좌측 사이드바 + 멀티페이지 구조 설계
- 8개 메뉴 라우팅 구현
- 전체 레이아웃 컴포넌트
- 로고를 `logo_SKKU_colored` 또는 `logo_SKKU_black`으로 교체

### Teammate 2: 페이지 컴포넌트 구현
- Superpowers 계획의 **Chunk 3** (대시보드 분해) 실행
- **추가**: `후보자 검증` / `채용 진행` / `채용 완료` / `학과장 Action` 4개 페이지 신설
  - 상단: 프로세스 흐름도/타임라인 컴포넌트
  - 하단: 해당 단계 액션 영역
  - 뼈대 + 플레이스홀더 데이터로 구성
- 기존 원테이블 페이지를 `한 눈에 보는 채용 원테이블` 메뉴로 재배치

### Teammate 3: 권한 시스템 & 디자인 정비
- Superpowers 계획의 **Chunk 2** (DB 마이그레이션 + 권한 시스템 + 매트릭스 UI) 실행
- `계정관리` 페이지: 가입된 사용자 목록 + 권한 할당/수정 UI
- Superpowers 계획의 **Chunk 4** (기존 페이지 리스타일) 실행
- 토스증권 스타일 감성으로 전체 UI 정비 (포인트 컬러: 딥그린)
- 로그인 화면 디자인도 리스타일

### Teammate 4: 리뷰 & 통합
- 기존 기능이 깨지지 않았는지 확인
- 각 teammate 결과물 통합
- 8개 메뉴가 모두 사이드바에 있는지 확인
- `후보자 검증` / `채용 진행` / `채용 완료` / `학과장 Action` 페이지가 존재하고 라우팅 되는지 확인
- 로고가 `logo_SKKU_colored` 또는 `logo_SKKU_black`으로 일관 적용되었는지 확인
- `npm run build` 통과 확인
- `CLAUDE_HANDOFF.md` 업데이트

각 teammate는 `codex-subagent`로 코딩 작업을 위임해.
