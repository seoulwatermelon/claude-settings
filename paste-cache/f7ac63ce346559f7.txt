Codex에게 코드 리뷰를 위임하되:
1. 먼저 대상 파일을 Read로 확인
2. Codex에 리뷰 요청 (model: gpt-5, reasoningEffort: high)
3. 결과를 정리해서 [심각/주의/참고] 등급으로 분류
4. 3줄 이내 요약만 반환
```

이렇게 하면 "코드 리뷰해줘"라고만 말해도 Claude가 자동으로 `codex-review` Skill을 호출하고, fork된 컨텍스트에서 Codex가 실제 리뷰하고, 메인 세션에는 요약만 돌아옵니다.

---

**Step 3: Agent Teams + Skills 조합 (최종 형태)**

Agent Teams를 쓸 때 각 Teammate에게 특정 Skill을 사용하라고 지시합니다:
```
프로젝트 전체 리팩토링을 진행해줘.

팀 구성:
- Teammate 1 (API): /codex-implement 스킬로 API 레이어 리팩토링
- Teammate 2 (Test): /codex-test 스킬로 테스트 코드 작성
- Teammate 3 (Review): /codex-review 스킬로 1, 2번 결과 크로스 리뷰

각 teammate는 codex-subagent의 sessionId를 활용해 컨텍스트를 유지하고,
결과는 간결한 요약으로만 보고해.
```

토큰이 절약되는 구조:
```
내 세션 (Orchestrator) ─ 토큰 최소 사용
  ├─ Teammate 1 ─ fork된 별도 컨텍스트
  │    └─ Codex MCP ─ Claude 토큰 0 (OpenAI 토큰 사용)
  ├─ Teammate 2 ─ fork된 별도 컨텍스트  
  │    └─ Codex MCP ─ Claude 토큰 0
  └─ Teammate 3 ─ fork된 별도 컨텍스트
       └─ Codex MCP ─ Claude 토큰 0
