# 한글(HWPX) 보고서 줄 넘김 규칙

> 사용자 확정(2026-11-05). 모든 프로젝트에서 한글 보고서·표를 만들 때 적용. 상세는 hwpxskill SKILL.md "줄 넘김 규칙".

- 줄이 넘어갈 때 **공백(띄어쓰기 2~3칸)으로 글머리에 맞추지 않는다.** 공백 정렬은 한글에서 어긋나 보인다.
- **본문**: 한 항목을 한 문단으로 통째로 쓰고, 둘째 줄은 **내어쓰기**(음수 intent 문단모양)로 번호·글머리 뒤에 맞춘다. 문장을 손으로 잘라 여러 문단으로 나누지 않는다.
- **표 셀**: 손으로 자르지 않는다. `- `·`1. `·`① ` 항목마다 한 문단 + 내어쓰기, **좌측정렬**, 한글 **어절 단위** 줄바꿈(`breakNonLatinWord="BREAK_WORD"`; `KEEP_WORD` 는 글자 단위). skku_report 는 `r.table(..., hang_left=True)`.
- 사용자가 "shift+enter로 맞춰"라고 하면 공백 대신 문단 내 정렬(내어쓰기)로 맞추라는 뜻이다.
- 표의 첫 행·첫 열(행·열 제목)은 굵게.
- 규정 조항을 인용하면 붙임에 그 조 전체(항·호·목)를 싣고 인용한 항만 굵게 표시한다.
